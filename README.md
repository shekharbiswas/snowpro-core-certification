# SnowPro Core Certification Prep

Personal study notes, resources, and practice tracking for the **SnowPro Core Certification** exam.

## About the Certification

The SnowPro Core Certification demonstrates knowledge to implement and migrate to Snowflake — covering platform architecture, secure/scalable solution design, and core operations.

**Official exam page:** https://learn.snowflake.com/en/certifications/snowpro-core/

## Exam Domains Covered

- Perform data loading and transformation
- Monitor and optimize virtual warehouse performance and concurrency
- Execute DDL and DML queries
- Use structured, semi-structured, and unstructured data
- Use cloning, Time Travel, and Fail-safe to manage data
- Facilitate Secure Data Sharing among different Snowflake accounts
- Design and manage the structure of a Snowflake account
