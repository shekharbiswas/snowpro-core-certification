# Study Plan

A suggested 4-week plan. Adjust pace based on your prior Snowflake experience.

## Week 1 — Foundations
- [ ] Snowflake architecture: storage, compute (virtual warehouses), cloud services layer
- [ ] Editions & pricing model basics
- [ ] Account structure: organizations, accounts, databases, schemas
- [ ] Roles & access control (RBAC), users
- [ ] Read: Snowflake "Key Concepts & Architecture" docs

## Week 2 — Data Loading & Transformation
- [ ] Loading data: `COPY INTO`, stages (internal/external), file formats
- [ ] Snowpipe (continuous loading)
- [ ] Semi-structured data: VARIANT, JSON, Parquet, `FLATTEN`
- [ ] Unstructured data handling
- [ ] Transformations during load, streams & tasks basics

## Week 3 — Performance, DDL/DML, Data Protection
- [ ] Virtual warehouse sizing, scaling (multi-cluster), concurrency
- [ ] Query performance: caching, clustering keys, query profile
- [ ] Core DDL (`CREATE`, `ALTER`, `DROP`) and DML (`INSERT`, `UPDATE`, `MERGE`, `DELETE`)
- [ ] Cloning (zero-copy clone)
- [ ] Time Travel & Fail-safe — retention periods, use cases, differences

## Week 4 — Data Sharing, Review & Practice
- [ ] Secure Data Sharing: shares, providers/consumers, reader accounts
- [ ] Data Marketplace basics
- [ ] Full review of all domains
- [ ] Take 2+ full-length practice exams
- [ ] Review weak areas identified from practice exams
- [ ] Schedule and take the real exam
